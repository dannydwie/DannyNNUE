# SimpleLogicsNNUE

SimpleLogicsNNUE is a UCI chess engine project designed for DroidFish.

## Project Goals

- UCI chess engine
- Alpha-beta search
- Iterative deepening
- Quiescence search
- Transposition table
- Move ordering
- NNUE evaluation
- Android ARM64 build
- DroidFish compatibility
- Testing against Stockfish

## Development Roadmap

1. UCI engine foundation
2. Stronger search
3. Transposition table and quiescence
4. NNUE evaluation
5. Android ARM64 build
6. DroidFish integration
7. Benchmark against Stockfish
